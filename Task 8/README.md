# Task 8 – Bank Marketing Decision Tree

This project predicts whether a customer will subscribe to a bank product using a Decision Tree.

## Steps Done
1. Loaded the bank marketing dataset
2. Cleaned and encoded categorical values
3. Split data into train and test sets
4. Trained a Decision Tree classifier
5. Visualized the tree
6. Tested the model and printed accuracy
7. Wrote simple decision rules

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Output
- Trained Decision Tree model
- Tree visualization image
- Classification report

## Conclusion
The Decision Tree helps understand which features affect customer subscription and provides simple decision rules.

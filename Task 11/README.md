# SVM Classification Project

## Description
This project trains a Support Vector Machine (SVM) model for a classification problem.

## Steps Performed
```
Load dataset
Scale features using StandardScaler
Split data into train and test sets
Train Linear SVM
Train RBF SVM
Tune hyperparameters using GridSearchCV
Evaluate using confusion matrix and classification report
Plot ROC curve and calculate AUC
Save final trained model
```

## Libraries Used
```
scikit-learn
pandas
matplotlib
joblib
```

## Output
```
Best SVM model
Performance metrics
Saved model file (svm_best_pipeline.pkl)
```

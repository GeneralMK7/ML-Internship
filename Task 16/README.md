# Hyperparameter Tuning using GridSearchCV

## Overview

This project demonstrates how to use **GridSearchCV** to find the best parameters for a machine learning model.

## Dataset

* Breast Cancer dataset from `sklearn`

## Steps

1. Import libraries
2. Load dataset
3. Split features and target
4. Scale the data
5. Split into train and test sets
6. Apply GridSearchCV on SVM model
7. Find best parameters
8. Evaluate model performance
9. Compare with default model

## Model

* Support Vector Machine (SVM)

## Result

* Best parameters found using GridSearchCV
* Tuned model compared with default model

## Conclusion

Hyperparameter tuning improves model performance compared to the default model.

# Digit Classification using KNN

## What this project does
This project classifies handwritten digits (0–9) using the KNN algorithm.

## Dataset
- Sklearn digits dataset
- 8×8 digit images

## Steps
1. Load dataset
2. Scale features
3. Train KNN
4. Test the model
5. Show predictions

## Tools Used
- Python
- Scikit-learn
- Matplotlib

## Result
The model predicts digits correctly and shows the output images.

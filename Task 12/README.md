# K-Means Customer Segmentation

## Task

Customer segmentation using **K-Means clustering** on the Mall Customers dataset.

## Dataset

* Mall Customers Dataset
* Features used:

  * Annual Income
  * Spending Score

## Steps Performed

1. Loaded the dataset
2. Dropped CustomerID column
3. Scaled the features using StandardScaler
4. Used Elbow Method to find optimal K
5. Applied K-Means clustering
6. Visualized customer clusters
7. Added cluster labels to dataset
8. Saved segmented data as CSV

## Output

* Elbow plot
* Cluster visualization
* Segmented customer dataset

## Tools Used

* Python
* Scikit-learn
* Matplotlib
* Seaborn

## Result

Customers were grouped into 5 clusters based on income and spending behavior for better business insights.

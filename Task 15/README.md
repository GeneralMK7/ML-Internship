# Machine Learning Pipeline (Task 15)

## Overview

This project builds a simple machine learning pipeline using the Breast Cancer dataset.
It trains models, evaluates them, and compares their performance.

## Dataset

* Built-in dataset from `sklearn`
* Breast Cancer dataset
* Binary classification problem

## Steps

1. Load dataset
2. Split data into train and test sets
3. Scale features
4. Train models (e.g., Logistic Regression, SVM)
5. Evaluate performance using metrics
6. Compare results

## Models Used

* Logistic Regression
* Support Vector Machine (SVM)

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score

## Output

* Model performance metrics
* Comparison table of models
